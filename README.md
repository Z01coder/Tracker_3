# Такт — командный трекер задач

Деловой веб-трекер задач малой команды (2–5 человек): проекты, канбан-доска
(«Бэклог / В работе / На проверке / Готово»), приоритеты, исполнители,
дедлайны и комментарии. Вход по логину и паролю, две роли:
**админ** (управление пользователями и проектами, полные права)
и **программист** (работа с задачами и комментариями).

Учебный кейс по реальному заказу (упрощено: автономный трекер, без интеграции в сайт заказчика);

## Стек

- **Node.js** (LTS, проверено на 22+), **Express 5** — сервер и API
- **SQLite** через `better-sqlite3` — данные на сервере (файл `db/task.db` создаётся автоматически)
- **bcryptjs** — пароли хранятся только в виде хэшей
- **express-session** — сессии в cookie (`takt.sid`)
- **Ванильный HTML/CSS/JS** на клиенте — без фреймворков и сборщиков
- Шрифт IBM Plex Sans (Google Fonts) с системным fallback — не ломается без сети

## Локальный запуск

Нужен Node.js LTS (проверялось на 22+). В каталоге проекта:

```bash
npm install
npm start
```

Откройте `http://localhost:3003` — сервер слушает `0.0.0.0:3003`.

При первом старте база создаётся автоматически и наполняется демо-данными:
1 проект «Сайт CakePHP — поддержка», 10 задач по всем статусам и приоритетам,
4 комментария. Повторные запуски данные не затирают и не дублируют.

## Что сознательно упрощено (в рамках MVP)

- Нет самостоятельной регистрации и восстановления пароля — только админ.
- Нет вложений файлов, уведомлений (e-mail/пуш) и истории изменений.
- Перемещение задач — кнопками «←/→», drag&drop не делается.
- Сессии в памяти процесса: при рестарте сервера всем нужно войти заново.
- SQLite — один файл, без миграционного инструмента; схема через CREATE TABLE IF NOT EXISTS.

## Проверка после деплоя (минимальный сценарий)

1. Вход `boss1`/`Boss#2026` → список проектов, счётчики по статусам.
2. Открыть доску → задача «Баг: рассылка падает с ошибкой 500» — критический,
   просрочена (левая красная полоса).
3. Создать задачу → выдвинуть по статусам кнопками «→» → прокомментировать.
4. «Пользователи» → создать учётку → выйти → войти новой учёткой.
5. Выйти → вход `dev1`/`Dev#2026` → убедиться: «Пользователи» и «Создать проект» недоступны.
